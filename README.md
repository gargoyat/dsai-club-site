# DSAI Club | IIT Bhilai — Official Website

Welcome to the official repository for the **Data Science and Artificial Intelligence (DSAI) Club at IIT Bhilai**, built for the 24-hour OpenLake HelloWorld Hackathon. 

---

## 🌟 About the Project
This website is designed to introduce newcomers to the DSAI Club with zero context, taking them through our mission, core activities, leadership, and open-source projects. Built using modern vanilla web technologies, the site features custom audio synthesis, an interactive machine learning training canvas, a retro developer terminal, and a responsive dark/light theme switcher.

---

## 🚀 Key Features
- **The DSAI Alien Observer**: An interactive alien system observer in the bottom-left corner whose eyes actively track the user's cursor and dynamically move in the opposite direction for a depth-perception parallax effect.
- **Live Polynomial Regression Playground**: A built-in machine learning sandbox where users can click to drop data points and watch a Degree-2 polynomial curve actively train and fit the data in real-time, complete with a live Mean Squared Error (MSE) loss dashboard.
- **DSAI OS Terminal**: A fully functional floating terminal widget where users can execute commands (`help`, `team`, `ping`, `clear`) and even complete an interactive **"Gradient Descent" AI mini-game** by typing `learn`.
- **Theme Switcher**: Instant transition between a blazing Light Orange theme and a sleek Cyberpunk Dark theme.
- **Synthesized Web Audio API**: Zero external audio files required—all sound effects (hover blips, button clicks, typing mechanics, tire screeches, and explosions) are mathematically synthesized directly in the browser.
- **3D Mouse-Tracking Cards**: Interactive elements that tilt and rotate in 3D space based on the user's mouse coordinates.

---

## 🛠️ Tech Stack & Assets
- **Frontend**: HTML5, CSS3 (Custom Glassmorphism, CSS Variables, Keyframe Animations), Vanilla JavaScript (DOM manipulation, Intersection Observers, Canvas API, Web Audio API).
- **Icons & Fonts**: FontAwesome 6.5.1, Google Fonts (Space Grotesk, Montserrat).
- **Images & Logos**: Official IIT Bhilai Institute logo, DSAI Club logo, and campus event media retrieved from official channels and social media handles.
